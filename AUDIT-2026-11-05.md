## 2. Security — High / Medium

- H1 `/api/notifications` `order_created` sends a branded email + SMS to any address the caller supplies; `.or()` filter built from input.
- H2 Customer-controlled values are put unescaped into email HTML (`lib/notifications.ts`).
- H3 Reviews are inserted as `approved` and can be edited freely (no moderation).
- H4 Anyone can add items to another guest's order.
- M1 Cron endpoint is open if `CRON_SECRET` is unset. M2 reCAPTCHA never checked server-side.
- M4 Blog/help HTML sanitizer is regex-based and bypassable. M5 No CSP; conflicting X-Frame-Options.
- M6 Old admin middleware failed open on errors. **Fixed on branch** (fails closed).
- M7 All coupon codes are publicly readable. Modules page "PIN" `6526` is hardcoded in client JS.
